# Checklist LGPD

- [x] Coleta pública mínima: o site não pede cadastro nem dados de saúde.
- [x] Dados privados ficam atrás de login e não aparecem em URLs públicas.
- [x] Há estruturas para consentimentos, solicitações de privacidade e logs de auditoria.
- [x] Dados sensíveis foram separados do perfil geral no banco.
- [ ] Publicar política de privacidade e termos revisados juridicamente.
- [ ] Definir prazo de retenção, responsável pelo tratamento e processo de resposta a solicitações.
- [ ] Registrar consentimento para mensagens antes de automações.
- [ ] Configurar criptografia de campos clínicos antes de coletá-los pela interface.
- [ ] Treinar quem terá acesso aos dados e testar exportação/anonimização.

O sistema não realiza diagnóstico médico e dados de saúde devem ser fornecidos apenas quando necessários ao procedimento.
